# Kyushu Autumn 2026 — Offline PWA

แอปออฟไลน์สำหรับทริปคิวชู 25 พ.ย. – 8 ธ.ค. 2569
รวมแผนเดินทาง 14 วัน · คู่มือถ่ายภาพ · เช็คลิสต์เตรียมตัว

## ติดตั้ง (GitHub Pages)

1. สร้าง repo ใหม่ เช่น `kyushu-2026`
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ไว้ที่ root ของ repo
3. Settings → Pages → Source: `main` branch, folder `/ (root)` → Save
4. รอสักครู่แล้วเปิด `https://<username>.github.io/kyushu-2026/`

## เพิ่มลงหน้าจอ iPhone

1. เปิดลิงก์ด้วย **Safari** (ต้องเป็น Safari เท่านั้น Chrome บน iOS ติดตั้งไม่ได้)
2. ปุ่มแชร์ → Add to Home Screen
3. เปิดแอปจากหน้าจอหนึ่งครั้งขณะต่อเน็ต เพื่อให้แคชไฟล์ครบ
4. หลังจากนั้นใช้งานออฟไลน์ได้เต็มรูปแบบ

## ไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวแอปทั้งหมด (เนื้อหาฝังอยู่ในไฟล์นี้) |
| `fonts.css` | ฟอนต์ Sarabun / Chonburi / IBM Plex Sans Thai แบบ base64 |
| `pg.css` | สไตล์ส่วนคู่มือถ่ายภาพ |
| `sw.js` | service worker สำหรับออฟไลน์ |
| `manifest.json` | ข้อมูลแอป ไอคอน ชื่อ |
| `icons/` | ไอคอน 192 / 512 |

## อัปเดตเนื้อหา

เนื้อหามาจาก `kyushu_autumn_2026_magazine_v1.5.html` และ `kyushu-photo-guide-v3.3.html`
ถ้าแก้สองไฟล์นั้น ให้รันสคริปต์ `build_pwa.py` ใหม่เพื่อสร้างแอป

**สำคัญ:** ทุกครั้งที่อัปเดต ให้แก้เลขเวอร์ชันแคชใน `sw.js` บรรทัดแรก
(`const CACHE='kyushu-v1'` → `kyushu-v2`) ไม่งั้นเครื่องที่ติดตั้งไว้แล้วจะยังเห็นของเก่า
